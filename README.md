📊 Facebook Ads Performance Dashboard (Power BI)
📌 Project Overview

This project is part of Task 2 of my Data Science & Analytics Internship at Future Interns.

The objective of this project is to analyze Facebook Ads campaign performance data and build an interactive Power BI dashboard that helps businesses evaluate marketing effectiveness and optimize ad spend using data-driven insights.

🎯 Key Objectives

Track overall campaign performance

Understand user engagement and conversions

Identify high-performing age groups and genders

Analyze spend efficiency using key marketing KPIs

📈 Dashboard Highlights

The dashboard provides insights into:

Total Spend

Total Impressions

Total Clicks

Total Conversions

Click-Through Rate (CTR %)

Cost Per Click (CPC)

Visual Analysis Includes:

📉 Ad Performance Trend (Impressions, Clicks & Conversions over time)

👥 Spend Distribution by Gender

🎯 Conversion Rate by Gender

👶 Total Spend by Age Group

📊 Conversion Rate by Age & Gender

The dashboard is designed in dark mode for better readability and professional presentation.

🛠 Tools & Technologies Used

Power BI

CSV Dataset (Facebook Ads Performance Data)

DAX (Calculated Measures)

Data Modeling & Visualization

Marketing Analytics Concepts

📊 KPIs Used

CTR (%) = (Total Clicks / Total Impressions) × 100

CPC = Total Spend / Total Clicks

Practical understanding of digital marketing analytics

Translating raw ad data into actionable insights

Designing business-ready dashboards

Applying KPIs used by marketing and growth teams
